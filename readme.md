# Guardian Key 🛡️

An AI-enhanced emergency alert mobile app that allows users to discreetly call for help by pressing both volume keys simultaneously.

## 🚀 Core Features
- **Stealth Trigger**: Press both volume keys to activate emergency mode
- **AI Voice Analysis**: Automatically detects keywords like "help" and aggressive tones
- **Auto-Recording & Cloud Backup**: Records audio and uploads to secure cloud storage
- **Smart Alerting**: Sends location and audio evidence to emergency contacts

## 🛠️ Prototype Overview
This repository contains the conceptual framework for Guardian Key:
- `docs/` - Project documentation and wireframes
- `android/` - Android volume key listener example
- `ai-model/` - Python script for voice analysis simulation

## 📱 How It Works
1. User sets up emergency contacts in the app
2. In emergency: press both volume keys for 2 seconds
3. App automatically records and analyzes audio using AI
4. If threat detected, app sends alert with location and audio clip
