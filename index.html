Guardian Key

An AI-enhanced emergency alert app that allows users to discreetly call for help by pressing both volume keys simultaneously.

Project Overview

Guardian Key is a mobile application designed to help individuals in dangerous situations quickly and discreetly alert emergency contacts. By simply pressing both volume keys simultaneously, the app activates an emergency mode that records audio, analyzes it with AI for threats, and automatically sends alerts with location data.

How It Works

1

Setup

User installs the app and configures emergency contacts in the settings.

2

Trigger

In an emergency, user simultaneously presses both volume keys for 2 seconds.

3

Recording & Analysis

App automatically starts recording and uses AI to analyze the audio for threats.

4

Alert

If a threat is detected, app sends alert with location and audio evidence to emergency contacts.

Code Implementation

Below is a simplified version of the volume key detection logic:

// Volume Key Detection for Android
public class VolumeKeyService extends Service {
    private boolean volumeUpPressed = false;
    private boolean volumeDownPressed = false;
    
    @Override
    public boolean onKeyDown(int keyCode, KeyEvent event) {
        if (keyCode == KeyEvent.KEYCODE_VOLUME_UP) {
            volumeUpPressed = true;
        } else if (keyCode == KeyEvent.KEYCODE_VOLUME_DOWN) {
            volumeDownPressed = true;
        }
        
        // Check if both keys are pressed within 500ms
        if (volumeUpPressed && volumeDownPressed) {
            triggerEmergencyMode();
            resetKeys();
            return true;
        }
        
        new Handler().postDelayed(this::resetKeys, 500);
        return super.onKeyDown(keyCode, event);
    }
    
    private void triggerEmergencyMode() {
        startRecording();
        new Thread(() -> analyzeAudioWithAI()).start();
        sendEmergencyAlert();
    }
}
